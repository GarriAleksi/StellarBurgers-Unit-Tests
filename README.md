Unit tests for a Java-based burger ordering system used in the Stellar Burgers application.

This project includes tests for the core classes: Bun, Burger, Ingredient, and IngredientType. The tests are written using JUnit 4, Mockito, and parameterized testing where appropriate.
Code coverage is tracked with Jacoco, aiming for at least 70% coverage.
